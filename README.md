# Distributed Banking Platform

Fault-tolerant banking backend using the saga pattern for distributed transactions with OAuth2 security.

> ⚠️ Work in progress — starter scaffold. Core logic is stubbed and marked with `TODO`s.

## Tech stack
Java · Spring Boot · Spring Cloud · MySQL · Resilience4j · OAuth2

## Getting started
```bash
mvn spring-boot:run
```
